## Identificação do Tema

**Tema:** *Gremlins*

**Título do projeto:** **Gremlins: Night Light**

O projeto consiste no desenvolvimento de um jogo inspirado no universo de *Gremlins* (1984), utilizando como principal elemento de gameplay uma **lanterna em um ambiente escuro**.

Na fase, o jogador deve utilizar a lanterna para encontrar os Gremlins presentes no cenário. Quando a luz é direcionada corretamente para um Gremlin, ele é eliminado e o jogador recebe pontos.

Caso a lanterna seja utilizada incorretamente, o jogador perde uma vida. Ao perder todas as vidas, a partida é encerrada, os créditos são apresentados e, posteriormente, o jogador retorna ao Menu Inicial para iniciar uma nova partida.

O cenário da fase foi desenvolvido a partir de um **esboço produzido pela dupla**, utilizando uma composição baseada em **ponto de fuga**. O processo visual parte do desenho original, passa por uma representação visual desenvolvida com auxílio de inteligência artificial e chega à implementação da fase jogável.

O projeto também contempla conceitos de desenvolvimento de jogos, como **interação por teclado e/ou mouse, colisões, física, junções (joints), raycast, iluminação e programação orientada a objetos**.
